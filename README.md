# 🌸 Sakura Genomics QC Tool 🌸

A beginner-friendly, lightweight Python tool built to parse biological genomic files and calculate vital quality control metrics like sequence lengths and GC Content percentages without heavy dependencies.

## 📐 Visual Blueprint & Architecture
Here is the aesthetic layout design created in Figma prior to developing the programmatic execution engine:

![Figma Design Blueprint](figma_design.jpg)

## 📊 Core Features
- **Aesthetic Visual Reporting**: Built with a custom baby pink color layout palette.
- **Dynamic File Ingestion**: Parses standard biological multi-line `.fasta` formats.
- **Data Validation & Cleaning**: Auto-normalizes mixed-case strings and drops lowercase errors.
- **Automated Logging**: Safely outputs structural parameter blocks to a permanent text report file.

## 🚀 How to Execute
1. Download this directory to your Windows machine.
2. Open your command prompt or VS Code terminal in this directory folder.
3. Run the following command:
   ```bash
   python Bioinformatics_1stProject.py
   ```
